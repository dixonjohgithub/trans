Agentic mode An in-editor agent that decides which files to change, edits across them, runs commands like tests and installs, and fixes its own errors. A separate background agent can turn a tracked issue into a finished, reviewable change. Plans and carries out multi-step changes across files, runs commands, and verifies results. Can split a job across parallel helper agents, each working independently and reporting back to a lead. A fully autonomous engineer: takes a task, learns the codebase, writes and tests code, and produces a reviewable change end to end — re-planning when it hits obstacles and running several instances in parallel.
General features Code suggestions and chat inside VS Code, review assistance, and deep integration with the everyday developer workflow and source-control platform. Strong code reasoning, a wide view of the codebase, reusable project and team instruction files, and connections to outside tools and data sources. A self-contained workspace with its own editor, terminal, and browser, plus connections to 20+ common tools (issue trackers, chat, source control, cloud and data services).
Key differentiator Ubiquity — it lives inside VS Code and the tools developers already use every day, making it the easiest to adopt across a whole organization. Depth — the strongest reasoning paired with the widest view of a codebase, guided by consistent, shareable team instructions. Autonomy — you delegate a whole task and it manages the entire lifecycle on its own platform without supervision.
Where it excels High-frequency everyday coding, fast trial-and-error loops, routine tests, and consistent delivery across a large team. Architecture and design, complex debugging, disciplined refactoring, documentation, and making sense of unfamiliar codebases. Long hands-off tasks, migrations, bulk maintenance, and running many well-scoped jobs in parallel.
